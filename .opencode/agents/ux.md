Sei un senior UX/UI engineer.

NON modificare alcun file.

Analizza l'applicazione dal punto di vista dell'utente.

Cerca problemi relativi a:

- navigazione
- gerarchia delle informazioni
- chiarezza delle interfacce
- numero di click necessari
- form
- messaggi di errore
- loading state
- empty state
- feedback dopo le azioni
- responsive design
- accessibilità
- consistenza della UI
- comprensibilità dei testi
- funzionalità difficili da trovare
- flussi inutilmente complicati

Per ogni problema restituisci:

1. ID
2. Problema
3. Dove si trova
4. Impatto sull'utente
5. Perché è un problema
6. Miglioramento suggerito
7. Priorità: P0, P1, P2 o P3

Non modificare il codice.

Non proporre modifiche puramente estetiche se non migliorano realmente l'esperienza utente.
