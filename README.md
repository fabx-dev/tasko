# Tasko

TUI todo list in italiano e inglese: kanban, pomodoro a cicli con pause, statistiche, template, backup e multilingua.

## Installazione

```bash
pipx install .
# oppure
pip install .
```

## Avvio

```bash
tasko
```

Tasti principali: `n` nuovo, `s` sotto-task, `Space` stato, `Enter` dettagli, `o` pomodoro, `k` statistiche, `/` cerca, `m` menu, `h` aiuto, `q` esci.

I dati stanno in `~/.todo_*.json`. Lingua auto da sistema (`TASKO_LANG=it|en` per forzarla).
